# Changelog

## Unreleased

### Added

- Initial static contact-management application with create, view, edit, delete, and search workflows, including support for distinct contacts sharing a phone number.
- Browser-profile `localStorage` persistence, validated stored data, confirmation-gated recovery, and visible handling of failed saves.
- Responsive interface, keyboard-operable controls, accessible status and validation feedback, and a local-storage privacy notice.
- Vite/TypeScript development and test toolchain, unit/integration/browser tests, and static-host security headers.
- Project requirements, architecture, design and code reviews, implementation plan, verification record, and developer documentation.
